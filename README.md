# Learning to Code with AuDHD

A learning application in planning, focused on understanding, reviewing, and troubleshooting code written by AI agents.

Created by James Lane. My experience with autism and ADHD shapes the project: learning needs a visible payoff, room for personal interests, and a clear path back after a break.

The goal is to help learners build a mental model of software: what each component does, how components connect, where failures can occur, and why a particular technology fits a problem.

## Current stage

This repository is at the planning stage. There is no runnable application or selected production stack yet. Product requirements and the decision journal will be reviewed through pull requests before implementation.

Follow the [planning and review work](https://github.com/Angry-TacoZ/learning-to-code-with-audhd/pulls) for the proposed learning experience, architecture questions, and delivery approach.

The working title is provisional. Licensing has not yet been selected.
