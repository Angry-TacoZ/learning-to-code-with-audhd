# Security

This project is in planning and has no deployed application or supported release yet.

Report suspected exposed credentials or vulnerabilities privately through the repository's **Security -> Report a vulnerability** option. Do not put a working exploit, private credential, or user data in a public issue. If private reporting is unavailable, use the contact listed on [James's GitHub profile](https://github.com/Angry-TacoZ) to arrange a private report without sending secrets.

Include the affected file or commit, impact, and a reproduction using synthetic data. Response times are not guaranteed while the project is in planning.

Credentials belong outside Git and outside browser-delivered code. Future exercises will use fake secrets and controlled services. Detailed runtime isolation and account-security requirements are recorded in the [implementation plan](docs/implementation-plan.md).
